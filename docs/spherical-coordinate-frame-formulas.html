Сферическая система координат диаграммы ЭПР

Система задаётся не географическими названиями углов, а ориентированным ортонормированным базисом.

  • P — направление полярной оси.
  • X — направление нулевой долготы, то есть φ = 0.
  • Q = P × X — направление четверти оборота, то есть φ = 90°.

Общая формула Termin

r(θ,φ) =R[ sinθcosφX +cosθP +sinθsinφQ ]

Здесь θ — полярный угол, φ — угол вращения вокруг полярной оси, а R — радиус точки диаграммы.

Ориентация для данных Alliance

P=(0,−1,0), X=(1,0,0), Q=(0,0,1)

После подстановки получаются декартовы координаты:

x= Rsinθcosφ y= −Rcosθ z= Rsinθsinφ
Углы Полученное направление Смысл
θ = 0°, любое φ (0, −R, 0) Первый горизонтальный полюс
θ = 90°, φ = 0° (R, 0, 0) Направление нулевой долготы
θ = 90°, φ = 90° (0, 0, R) Верх диаграммы
θ = 180°, любое φ (0, R, 0) Второй горизонтальный полюс

Расчёт ЭПР

σдБ = 10log10 [4π ( |Eφ|2 + |Eθ|2 )]

Это соответствует формуле 10 lg(4π|E|²), где полный квадрат модуля поля равен сумме квадратов модулей двух компонент.

Итог: θ остаётся полярным углом, но его полярная ось лежит горизонтально и направлена вдоль −Y. Угол φ вращает направление вокруг этой горизонтальной оси. Поэтому θ в этой системе нельзя называть азимутом.
