  В приложении используется её непрозрачный вариант с тёмным фоном. Исходная
  генерация с альфа-каналом сохранена без изменений.
- **Предпочтительный логотип:** [12 · angular](wordmarks/12-termin-angular.png).
  Вариант 11 оставлен как альтернатива. Правки 13 и 14 не заменяют angular.
- **Последнее направление 3D:** [T с объёмом сзади](geometry/T-VOLUME.md).
  Передняя сторона взята без изменений из прежней модели-рельефа.
- Города и остальные варианты сохранены как эскизы для будущих применений.

## Структура

| Папка | Содержимое |
|---|---|
| `icons/` | Все 11 исходных генераций иконок и городов, промпты |
| `wordmarks/` | Все 4 генерации слова TERMIN, промпты |
| `references/` | Два исходных изображения пользователя, использованных как референсы |
| `geometry/` | Генераторы Blender, HTML-шаблон просмотра и описание каждого опыта |
| `tools/` | Экспорт выбранной T в форматы приложения |

Сохраняем исходники и решения. Воспроизводимые `.blend`, GLB, видео, кадры и
превью не храним: генераторы пишут их в игнорируемую папку `build/branding/`.
Исключение — три файла иконки в ресурсах редактора: они требуются действующему
контракту упаковки приложения и пересоздаются из единственного мастер-файла.
Отдельной копии мастера в runtime-ресурсах нет.

## Команды из корня репозитория

```sh
task branding:icon        # Python 3 + FFmpeg: PNG, BMP и ICO редактора
task branding:logo        # Blender 5.2: первоначальный объёмный логотип
task branding:t-volume    # Blender 5.2: выбранная T с достроенной задней стороной
task branding:sculpture   # Blender 5.2: отклонённый опыт с перекрученной трубой
```

К командам Blender можно добавить `-- --animate` для видео (нужен FFmpeg).
`-- --output PATH` меняет каталог результатов у всех генераторов.
После обновления иконки `task build` устанавливает её в SDK штатным способом.

Генератор последней T использует геометрию из `build_logo.py` и вспомогательные
функции из `build_sculpture.py`: скрипты сохраняются вместе. Blender-файлы не
являются исходниками этой серии экспериментов; будущие изменения модели нужно
вносить в генераторы.
