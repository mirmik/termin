# Six-foot spider step throughput

The Termin scene at `termin-spider-control@b2ccb29` and its MJCF export at
`twister-capper@227a485` have 28 DOFs. The matched experiment lands the robot,
moves one hip target by 5 degrees and returns to its starting stance. The
comparison uses the first 1000 steps to settle the robot and times the next
3000 steps at dt = 1 ms. The Termin entry point updates the physics-only scene.
The MuJoCo entry point sets the actuator control, runs mj_step and refreshes
end-of-step kinematics. Startup, rendering, observation and trace writing are
outside the timed blocks.

Linux x86-64, Ryzen AI MAX+ 395, logical CPU 2, Release SDK based on
`2b402a7dc`, MuJoCo 3.15.0. Each column is an independent process. Times are
the mean wall-clock microseconds per step in each run.

| Engine | Run 1 | Run 2 | Run 3 |
| --- | ---: | ---: | ---: |
| Termin before | 1580.6 | 1574.3 | 1573.9 |
| Termin with friction response cache and simplified convexity check | 815.7 | 816.5 | 816.0 |
| Termin also using previous support rows | 494.7 | 492.7 | 500.0 |
| MuJoCo | 12.6 | 11.4 | 11.4 |
| MuJoCo with 10 NoSlip iterations | 13.4 | 13.4 | 13.4 |

Before the change, six supporting feet required 18 response solves with the
same mass matrix and bilateral Jacobian. Reusing one factorization within that
loop gave 897 µs/step in an intermediate run. The 816 µs result also removes
the trivial minimum-norm solve for zero equalities and simplifies the
convexity check in the active-set solver. The four-second Termin traces before
and after those two changes agree exactly at all 4001 samples for body and foot positions, joint
coordinates, applied torques and target commands.

In the CPU profile at 816 µs/step (1239 samples), 59.5% of stacks include the active-set
QP solver and 47.9% include unilateral velocity projection. These shares overlap.
The matched experiment in twister-capper measures maximum foot displacement at
0.142 mm for Termin, 17.22 mm for standard MuJoCo and 0.136 mm with NoSlip 10.

## Reusing the supporting contacts

Position and velocity projection now try the previous supporting rows as
equalities with the current M, Jacobian, load and limits. Success requires
the full QP optimality checks. The regular solver handles a newly blocking
or released contact, and resolves load sharing on degenerate faces.

On steps 1000–3999 of the 1 ms sweep the instrumentation gave these counts.
Phase I finds a feasible point for the active-set search. The velocity column
includes both configuration passes.

| Stage | Calls to Phase I before | Calls to Phase I after | Accepted faces after |
| --- | ---: | ---: | ---: |
| Position projection | 3000 | 0 | 3000 |
| Velocity projection | 4977 | 0 | 6000 |
| Friction | 0 | 0 | — |

For landing, on steps 101–199, position and velocity projections together
went from 297 Phase I calls to two. These counts were taken in separate
instrumented runs at entry to Phase I, at acceptance of the hinted face and
at both projection call sites. Each instrumented trajectory matched the
corresponding uninstrumented run exactly. Across all four simulated seconds,
the new path and a cold solve of each identical hinted subproblem agreed
on status in all 11695 comparisons; the largest absolute differences in
primal and unilateral dual were 1.4e-15 and 2.3e-16 respectively.

At 0.5, 1 and 2 ms the maximum absolute differences from the reference
trajectory were below 2e-14 m per foot coordinate and 1.3e-10 N·m per
actuator. The 5 ms scenario is unstable on both builds. Body height first
crossed 1 m at 1.765 s on both, but individual foot coordinates differed by
up to 0.473 m later in the fall. All 1971 hinted subproblems on that new
trajectory were also replayed cold at identical inputs. Primal and dual
differences stayed below 7.2e-15 and 1.8e-15.

Two extra lift-off tests replace the hip command with a half-cosine ramp
from 0 to +0.55 or −0.55 radians over 1.000–1.240 s, then hold the final
target until 4 s. At 1 ms the middle left foot cleared 10 µm at 1.081 s
in the positive run; the rear and front left feet cleared it at 1.137 s
and 1.154 s in the negative run. All three events matched the reference
step. The loaded-contact mask (normal impulse >1e-8 N·s) matched on all
4000 steps of each run. Per-foot normal and tangential impulse differences
were below 6.4e-12 N·s.

The second friction pass still runs on every contact step in this trace.
Before the support-row optimization, the time from the first friction
solve returning to the second returning averaged 219 µs per step in late
stance. After the optimization this interval averaged 206 µs within a 516 µs
instrumented late-stance step on CPU 5. The first pass's midpoint correction, measured in the tangent
plane of a foot, was typically 38 µm there and reached 326 µm on landing.
This includes a physical configuration change. Card #3939 tracks whether
the corrected state can sometimes be certified without a second solve.

## Reproduction

Place all three checkouts side by side. From the Termin root, save the following
driver as `/tmp/time-spider.py`. It reuses the reference experiment's scene,
controller and step callbacks.

```python
import argparse
import sys
from pathlib import Path
from time import perf_counter_ns

sys.path.insert(0, str(Path("../twister-capper/scripts/spider").resolve()))
import run


def measure(args, joints, advance, observe):
    commands = [run.command(i * args.dt) for i in range(4000)]
    for angle in commands[:1000]:
        advance(angle)
    observe()
    elapsed = 0
    for start in range(1000, 4000, 100):
        batch = commands[start:start + 100]
        begin = perf_counter_ns()
        for angle in batch:
            advance(angle)
        elapsed += perf_counter_ns() - begin
        observe()
    print(f"{elapsed / 3000 / 1000:.2f} us/step")


run.record = measure
engine, noslip = sys.argv[1:]
args = argparse.Namespace(dt=.001, scene=run.SOURCE, model=run.MODEL,
                          noslip_iterations=int(noslip))
(run.run_termin if engine == "termin" else run.run_mujoco)(args)
```

```sh
taskset -c 2 sdk/bin/termin_python /tmp/time-spider.py termin 0
taskset -c 2 ../twister-capper/.venv/bin/python /tmp/time-spider.py mujoco 0
taskset -c 2 ../twister-capper/.venv/bin/python /tmp/time-spider.py mujoco 10
```

For a full trajectory, use the reference recorder before and after rebuilding.

```sh
sdk/bin/termin_python ../twister-capper/scripts/spider/run.py termin /tmp/spider.npz --dt .001
```
